# Label sources and links

MedSymp uses structured FDA label data for its automated screening and displays supporting excerpts directly in the results.

The **Search FDA labeling** link opens FDA’s FDALabel search tool at https://www.accessdata.fda.gov/scripts/cder/daf/index.cfm. It is a general search page, not a deep link to the exact selected record or a PDF. Search by drug name and review the correct product, strength and manufacturer.

The application no longer promises or attempts to resolve PDF URLs. The optional SPL relay is still used for structured text retrieval when configured; PDF indexing is not required. A **No** result means no relevant match in the checked label sections, not evidence that the medication cannot cause a symptom.
