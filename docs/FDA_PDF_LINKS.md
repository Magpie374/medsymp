# FDA PDF links

The app first attempts to retrieve a direct application-specific FDA PDF URL from openFDA Drugs@FDA. If this cannot be resolved, it offers verified reference PDFs for **CRESTOR (rosuvastatin tablets, 2024)** and **NovoLog (insulin aspart, 2023)** when the selected record matches those single-ingredient drugs. Such reference PDFs may not match the exact manufacturer or version of the SPL checked for symptom evidence. Other drugs fall back to the FDA application document page.

PDF links and symptom-evidence sources are distinct. Do not present reference PDFs as the exact or most current matching label.
